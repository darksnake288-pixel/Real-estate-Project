# Real Estate

Landing page for a real-estate brand: hero, about, property listings, customer testimonials, contact, and footer. Scroll animations use AOS.

**Live demo:** [real-estate-project-seven-kappa.vercel.app](https://real-estate-project-seven-kappa.vercel.app)

## Features

- Full-page marketing layout for listings and brand story
- Customer testimonials and contact section
- AOS scroll animations
- Responsive UI with Tailwind CSS v4

## Tech stack

| Area | Tools |
| --- | --- |
| UI | React 19 |
| Styling | Tailwind CSS 4 |
| Animation | AOS |
| Bundler | Vite 8 |
| Icons | react-icons |

## Getting started

```bash
git clone https://github.com/darksnake288-pixel/Real-estate-Project.git
cd Real-estate-Project
npm install
npm run dev
```

| Script | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run Oxlint |
